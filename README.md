Sum up 18 November's world news in one image. One 1024x1024 PNG summarising Wednesday 18 November 2026 in six panels: Trump arriving in Shenzhen for the US-China-Russia trilateral summit, the US-Iran strikes around the Strait of Hormuz, Ukraine's second-day strike on the Kerch Bridge, Cyclone Akvan's approach to India's east coast, Nvidia's record $115.8bn quarter, and the US losing its measles-free status.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the pre-built
`entry.png` to `/output/entry.png`. No network, no randomness — two runs
write identical bytes. Build the image from source with
`python3 build_image.py`.
